# ScamShield AI

ScamShield AI is a web-based AI-powered scam detection system developed as a mini project. The application helps users identify potential online scams by analyzing suspicious text messages, emails, and URLs. It provides a scam risk score and an explanation to help users make informed decisions and improve cybersecurity awareness.

## Features

- Analyze suspicious text messages
- Detect scam emails
- Scan URLs for potential phishing
- AI-generated scam risk score
- Detailed scam explanation
- User authentication
- Scan history
